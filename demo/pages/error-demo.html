Scenario 5: Fault Tolerance & Error Recovery

Resilience & Failure State Walkthrough

Credible is architected for zero-crash defensive cybersecurity: every failure path displays helpful, accessible user feedback and falls back safely to deterministic rules whenever possible.

Experiment A: Deterministic Fallback Mode (Works Without API Key)

Credible does not require an active Gemini API key or external cloud connectivity to protect users. When run without an API key, the system seamlessly operates in deterministic mode: 

# Stop existing backend process and restart without GEMINI_API_KEY:
set GEMINI_API_KEY=
python -m uvicorn app.main:app --port 8000

Expected Behavior: Go to Scenario 2 (Suspicious) and trigger a scan. Credible detects upfront fee requests and password demands using local deterministic rule engines, while the Side Panel displays a transparent limitation note indicating the AI service was bypassed.

Experiment B: Backend Offline / Network Error Recovery

Simulates a scenario where the backend server is unreachable or crashed: 

# Stop the backend terminal (Ctrl+C in your FastAPI uvicorn terminal)

Expected Behavior: Open Credible and click "Scan This Page". Instead of hanging, crashing, or opening DevTools errors, the Side Panel immediately presents an Apple-styled Error State Card:

  • States clearly: "Connection Failed — Unable to reach the Credible security analysis service".
  • Provides an interactive "Retry Analysis" button so the user can easily re-run once the backend is restarted.
  • Never displays sensitive internal error traces or unformatted JSON errors to the end user.
